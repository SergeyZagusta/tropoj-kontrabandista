# Тропой контрабандиста — Android-проект (Capacitor)

Игра упакована в нативный Android-проект на базе **Capacitor**. Сама HTML/CSS/JS игра
лежит в `www/index.html`, шрифты встроены локально (`www/assets/fonts`) — приложение
работает полностью офлайн.

Собрать сам APK здесь я не могу (нет доступа к серверам Google/Android SDK из этой
среды), но проект уже полностью готов. Проще всего собрать APK одним из двух способов:

## Способ 1 — Автоматически через GitHub Actions (рекомендуется, ничего ставить не надо)

1. Создай новый пустой репозиторий на https://github.com (публичный или приватный).
2. Загрузи туда содержимое этой папки целиком (через веб-интерфейс "Add file → Upload files"
   и перетащи все файлы и папки, включая скрытые `.github` и `.gitignore`,
   либо через git: `git init && git add . && git commit -m "init" && git remote add origin <URL> && git push -u origin main`).
3. Перейди во вкладку **Actions** в репозитории — сборка запустится автоматически
   (workflow "Build APK") и займёт пару минут.
4. Когда сборка завершится зелёной галочкой, открой её и внизу в разделе **Artifacts**
   скачай `tropoj-kontrabandista-apk` — это готовый zip с файлом `app-debug.apk`.
5. Перекинь APK на телефон и установи (может понадобиться разрешить установку
   "из неизвестных источников" в настройках Android).

Дальше при каждом изменении игры — просто заново загружаешь файлы в репозиторий,
и Actions сам пересоберёт APK.

## Способ 2 — Локально через Android Studio

1. Установи [Android Studio](https://developer.android.com/studio).
2. Открой папку `android/` этого проекта как проект Android Studio
   (Open → выбери папку `android`).
3. Дай Gradle синхронизироваться (скачает всё нужное сам).
4. Build → Build Bundle(s) / APK(s) → Build APK(s).
5. Готовый файл будет в `android/app/build/outputs/apk/debug/app-debug.apk`.

## Важные детали проекта

- **appId**: `com.smuggler.tropoj` (при желании смени в `capacitor.config.json` и
  пересобери — но проще один раз задать правильный сразу, т.к. Google Play не позволит
  сменить его после публикации).
- **Ориентация**: зафиксирована портретная (задано в `AndroidManifest.xml`).
- **Иконка приложения**: пока стандартная иконка Capacitor. Чтобы заменить на свою —
  подготовь квадратное изображение минимум 1024×1024 и используй инструмент
  https://icon.kitchen или Android Studio (Image Asset Studio: правый клик на `res` →
  New → Image Asset), это сгенерирует все нужные размеры иконок автоматически.
- Это **debug**-сборка APK — устанавливается и работает как обычное приложение,
  но для публикации в Google Play потребуется собрать `release`-версию с подписью
  (об этом можно попросить меня отдельно, когда дойдёт до публикации).
